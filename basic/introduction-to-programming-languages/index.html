编程语言介绍

本节我们来讨论一下采用什么技术可以构建目标应用，接下来可能会涉及很多陌生的技术，请不要感到害怕，它们只是构建应用的工具，不同的工具（技术）有不同的特性，我们需要结合目标应用的特点选择最合适的技术。我们先从编程语言开始介绍。

机器码、汇编语言和高级语言

Section titled “机器码、汇编语言和高级语言”

编程语言在计算机中运行，依赖于计算机中一个名为 CPU（中央处理器） 的硬件，由于设计理念和应用场景的不同，市面上出现了多种不同 指令集架构 的处理器，如 x86、x86-64（又称 x64）、ARM 和 RISC-V 等……CPU 是一个只能执行 机器码 的部件，机器码是由 0 和 1 组成的指令，类似于 10110000 01100001……。如果要让计算机执行任务，需要向它提供一组按照特定顺序排列的指令，这组指令的序列称为 程序，同一个操作对不同的指令集架构的 CPU 而言，需要使用的指令不一定一样。在早期，程序员确实需要手动输入完全由 0 和 1 组成的机器码，很难想象这是一种多么糟糕的体验。

Note

中央处理器（Central Processing Unit，简称 CPU），简称“处理器”，是计算机系统的运算和控制核心，被誉为计算机的“大脑”。它的核心功能是解释计算机指令以及处理计算机软件中的数据。

指令集架构（Instruction Set Architecture，简称 ISA）：是计算机体系结构中与程序设计有关的核心部分，它充当了计算机硬件与软件之间的一个关键接口与抽象层。

机器码（Machine Code）：是计算机的 CPU 能直接识别和执行的二进制指令代码。它是计算机硬件的“母语”，由一系列由 0 和 1 组成的二进制序列构成，是计算机程序最底层的表达形式。

程序（Computer Program）：是指为了得到某种结果而可以由计算机等具有信息处理能力的装置执行的代码化指令序列。

为了方便人们编写程序，发明了 汇编语言。汇编语言使用 助记符 来表示机器指令，使程序更易于阅读和编写，比如 ADD R1, R2, R3 通常表示把 R2 和 R3 的值相加，并把结果存入 R1。

Note

助记符（Mnemonic）：是汇编语言中用来表示机器指令操作码的符号名称，通常是一个英语单词或其缩写，用于帮助人们记忆和理解指令的功能。它是连接晦涩难懂的机器码与人类思维的关键桥梁。

汇编语言（Assembly Language），又称“符号语言”，是一种面向机器的低级程序设计语言。它通过使用 助记符（Mnemonic） 代替机器指令的操作码，用 地址符号或标号（Label） 代替指令或操作数的地址，从而将晦涩难懂的机器语言转化为人类相对易于阅读、理解和维护的文本形式。

程序以文本形式书写时，被称为 源代码，编写程序的过程被称为 编程。

Note

源代码（Source Code），也称为 源程序，是指未编译的、按照一定的程序设计语言规范书写的文本文件，是一系列人类可读的计算机语言指令。它是软件开发的核心产物，是程序员用编程语言（如 C、Python、Java）编写的原始代码。

编程（Programming）：是指为了让计算机解决特定问题，而设计、编写、测试和维护计算机程序的过程。

汇编语言仍然与具体的指令集架构紧密相关，不同处理器运行的汇编语言程序往往难以通用。为了摆脱对硬件的依赖，并提高开发效率，人们发明了多种 高级语言，比如 C 语言、Python、Java 等。以 Python 为例，同样的加法操作，把 r2 和 r3 的值相加并存入 r1，可以写成 r1 = r2 + r3。高级语言更加接近人类思维方式，需要通过 编译器 或 解释器 翻译成机器码后才能被执行。

Note

高级语言（High-level Programming Language）：是一种独立于机器硬件、面向过程或对象的计算机编程语言。它以人类的日常语言和数学公式为基础，使用接近人类思维的语法和结构，使程序员能够更专注于解决问题本身，而无需直接操作计算机底层的硬件和指令。

编译器（Compiler）：是一种将用某种源语言（通常是高级语言）编写的程序，一次性完整地转换成另一种等价的目标语言（通常是低级语言或机器语言）程序的软件系统。

解释器（Interpreter）：是一种计算机程序，能够将高级编程语言编写的源代码逐行翻译成机器可执行的指令，并立即执行这些指令。

编译型语言和解释型语言

Section titled “编译型语言和解释型语言”

前面我们提到过，计算机的核心是中央处理器，中央处理器只能处理机器码，高级语言需要转换为机器码才能被计算机运行，根据转换的方式可以将高级语言分为 编译型语言 和 解释型语言。编译型语言会先通过编译器将源代码转换成目标平台的机器码和可以在目标平台运行的 可执行文件，这个过程被称为“编译”，同一份源代码由于平台的差异会导致可执行文件存在差异。解释型语言会在程序运行时由解释器解析源代码并执行，通常不会提前生成与平台绑定的机器码可执行文件。

Note

编译型语言（Compiled Language）：在程序运行前通过编译器将源代码转换为目标平台机器代码，并生成可执行文件的编程语言。

解释型语言（Interpreted Language）：在程序运行时由解释器解析并执行源代码的编程语言，通常不提前生成机器码可执行文件。

可执行文件（Executable File）：计算机可以直接运行的文件，其中包含已经转换成机器代码的程序。

编译（Compilation）：把人类编写的源代码转换成计算机可以直接执行的机器代码的过程。

思考

解释型语言存在“编译”过程吗？

需要注意的是，现代编程语言的实现通常采用编译与解释的混合方式，例如 Java、Python 和 JavaScript 都使用 中间代码 或 即时编译 技术。

Note

中间代码（Intermediate Code / Intermediate Representation，简称 IR）：在源代码和最终机器代码之间的一种过渡形式的代码，用于表示程序的逻辑结构，便于编译器或虚拟机进一步处理和优化。

即时编译（Just-In-Time Compilation，简称 JIT）是一种程序执行技术，它的核心思想是：在程序运行过程中，将部分代码动态编译成机器代码，从而提高运行效率。

常见编程语言

Section titled “常见编程语言”

机器码和汇编语言存在适用场景、可维护性和开发效率等多方面的弱势，大多数人选择采用高级语言进行编程。如果没有特别的要求，机器码和汇编语言不在我们考虑的范畴之内。

截止到目前，已经发明了超过 1000 种高级语言，幸运的是，我们不用学会每一种语言才能开始编程，在 AI 帮助下，我们甚至不用完全学会一门编程语言就可以开始编程，即便没有 AI 的加持，很难说程序员在使用某一门语言编程时对该语言已经精通。
