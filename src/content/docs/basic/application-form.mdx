在 **图形界面** 普及之前，人们面对屏幕上的黑色方框来进行操作，将要执行的计算机操作通过命令的形式输入到计算机中，这种交互形式被称为 **CLI**，这个“黑色方框”被称为“**命令行窗口**”。日常使用的绝大多数应用都使用图形界面来交互，CLI 在开发和运营场景非常常见，现代操作系统仍然保留了 CLI。

<Aside type="note">
**图形界面**（**Graphical User Interface**，简称 **GUI**）：通过图形元素（如窗口、按钮、图标、菜单等）与用户进行交互的界面形式。

**命令行界面**（**Command Line Interface**，简称 **ClI**）：通过输入文本命令与计算机进行交互的界面形式。

**命令行窗口**：用于输入和执行文本命令的界面窗口，是命令行界面（CLI）的具体表现形式。
</Aside>

在图形界面环境下，常见的使用软件的方式之一是先在计算机上安装好客户端，通过客户端使用软件功能，如果运行在个人计算机（如 Windows 或 macOS）上，这种应用被称为**桌面应用**；如果运行在移动设备（如智能手机）上，这种应用被称为**移动应用**。因为软件安装到计算机上，通常具有更高的系统访问权限，比如访问本地文件、调用系统功能……

<Aside type="note">
**桌面应用**（**Desktop Application**）：安装并运行在个人计算机操作系统上的应用程序，通常通过图形界面与用户交互。

**移动应用**（**Mobile Application**）：运行在移动设备（如智能手机、平板电脑）上的应用程序。
</Aside>

另一种常见的使用软件的方式是打开浏览器，访问一个网站，这种应用被称为 **Web 应用**。相比桌面应用和移动应用，Web 应用运行在浏览器环境中，其对本地系统资源的访问通常受到更多限制。

<Aside type="note">
**Web 应用**（**Web Application**）：基于 Web 技术开发，通过浏览器访问和使用的应用程序。
</Aside>

我们在使用微信时，会遇到 **小程序**，这也是一种应用形态，小程序可以理解为运行在特定平台（如微信）中的轻量级应用，其开发技术与 Web 技术相似，但运行在平台提供的 **运行环境** 中，微信在这里被称为 **宿主应用**，常见的宿主应用有微信、支付宝、抖音等。

<Aside type="note">
**运行环境**（**Runtime Environment**）：为程序正常执行所提供的一整套软件和系统支持条件。

**小程序**：运行在特定平台（如微信、支付宝等）提供的运行环境中的轻量级应用程序。

**宿主应用**（**Host Application**）：为其他应用或模块提供运行环境和基础能力的应用程序。
</Aside>

随着小程序的发展，国内手机厂商推出了 **快应用**。快应用是一种由手机操作系统提供运行支持的轻量级应用形态，不依赖于微信、支付宝等宿主应用即可运行。

<Aside type="note">
**快应用**（**Quick App**）：由手机厂商联合推出的一种无需下载安装、可直接运行的轻量级应用形态，运行在手机系统提供的运行环境中。
</Aside>

CLI（命令行界面）和 GUI（图形界面）是交互方式的分类，桌面应用、移动应用、Web 应用、小程序、快应用等是常见的应用形态。应根据具体业务需求和使用场景进行选择一种或多种交互方式或形态进行开发。

<Aside type="tip" title="小结">
本节介绍了 CLI（命令行界面）和 GUI（图形界面）两种交互方式，和桌面应用、移动应用、Web 应用、小程序、快应用等常见的应用形态。

**交互方式对比**

| 项目 | CLI | GUI |
| :---: | :--- | :--- |
| 交互方式 | 输入文本命令 | 点击图形元素 |
| 输入方式 | 键盘输入命令 | 鼠标点击、触控 |
| 直观程度 | 较低 | 较高 |
| 学习成本 | 较高    | 较低      |
| 操作效率 | 熟练后较高 | 直观但可能较慢 |
| 资源占用 | 较低    | 较高      |

**常见的应用形态**

| 对比项 | 桌面应用 | 移动应用 | Web 应用 | 小程序 | 快应用 |
| :---: | :---- | :---- | :---- | :---- | :---- |
| 运行环境 | 操作系统（Windows/macOS） | 手机/平板操作系统（Android/iOS） | 浏览器 | 宿主应用（如微信） | 手机系统运行框架 |
| 是否安装 | 需要安装 | 需要安装 | 不需要 | 不单独安装 | 不需要安装 |
| 网络依赖 | 不一定 | 通常需要 | 通常需要 | 通常需要 | 通常需要 |
| 系统权限 | 较高 | 较高（受系统限制） | 受浏览器限制 | 受宿主限制 | 较高（受系统限制） |
| 性能    | 较高 | 较高 | 依赖浏览器 | 介于 Web 与原生之间 | 接近原生 |
| 安装方式 | 下载安装包 (.exe/.dmg)，需手动安装 | 应用商店下载，需完整安装 | 无需安装，输入网址即可访问 | 无需安装，扫码或搜索即用 | 无需安装，系统级链接直达 |
| 更新方式 | 用户手动更新或内置自动更新 | 应用商店更新 | 实时生效 (服务器端更新) | 开发者后台发布，用户无感更新 | 开发者后台发布，用户无感更新 |
| 获客/入口 | 官网下载、软件管家、预装 | 应用商店 (App Store/Google Play) | 搜索引擎、外链、书签 | 微信扫码、搜索、公众号、分享 | 	短信、浏览器、负一屏、语音助手 |
| 开发成本 | 高 (需适配多系统，或用电跨平台技术) | 高 (通常需 iOS/Android 双端开发) | 中 (一次开发，全平台运行) | 中 (需遵循各平台规范，如微信标准)| 中 (遵循快应用联盟标准) |
| 典型场景 | 专业办公、大型游戏、视频剪辑、编程 | 高频生活、社交、娱乐、随时随地的服务 | 信息查询、轻量工具、SaaS 管理后台 | 线下扫码点餐、电商转化、低频服务 | 	短信直达服务、硬件配网、临时查询 |
| 代表案例 | Photoshop, VS Code, Steam, Office | 微信，抖音，王者荣耀，淘宝 | Google Docs, Notion, 淘宝网页版 | 美团外卖 (小程序), 京东 (小程序)| 快递 100(快应用), 手机充值 (快应用) |
| 跨平台能力 | 较弱 | 较弱 | 强 | 依赖平台 | 依赖厂商系统 |
